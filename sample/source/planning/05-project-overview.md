## 2. 독서 기록 앱 샘플 - 왜 이 주제인가?

**독서 기록 앱**은 다음 이유로 기획서/기능 정의서 학습에 적합합니다.

1. **직관적**: 누구나 이해할 수 있는 일상적인 주제
2. **단순함**: 복잡한 비즈니스 로직 없음
3. **완결성**: 기획서 → 기능 정의서 → HTML 화면까지 전체 플로우 확인 가능
4. **실용적**: 실제로 만들 수 있는 수준의 범위

## 3. 문서 작성 흐름

```
1. 기획서 (04-reading-tracker.md)
   └─ 무엇을 만들지, 왜 만드는지, 화면은 어떻게 되는지

2. 기능 정의서 (feature-reading-tracker.md)
   └─ 각 기능의 입력/출력, 유효성 검사, 데이터 구조

3. HTML 화면 목업 (screens/*.html)
   └─ 실제 화면이 어떻게 보일지 시각적으로 확인
```

## 4. 화면 미리보기 사용법

독서 기록 앱 기획서([04-reading-tracker](./04-reading-tracker))를 열면:

- 오른쪽 사이드바에 **"화면 미리보기"** 버튼이 표시됩니다
- 버튼을 클릭하면 **3개의 화면**을 탭으로 전환하며 확인할 수 있습니다
  - 내 책장 (메인)
  - 책 상세
  - 읽은 책 추가
