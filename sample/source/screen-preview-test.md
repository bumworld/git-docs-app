# 스크린 미리보기 테스트

이 페이지는 스크린 미리보기 버튼을 테스트합니다.

사이드바의 "스크린 미리보기" 버튼을 클릭하면 HTML 화면을 미리볼 수 있습니다.

## 상태 정보

- **상태**: 확정 (confirmed)
- **버전**: v1.0

## 사용 방법

1. 우측 사이드바에서 스크린 미리보기 버튼을 클릭합니다.
2. 모달이 열리면 디바이스 크기를 선택합니다.
3. Mobile / Tablet / Desktop 탭으로 전환할 수 있습니다.
