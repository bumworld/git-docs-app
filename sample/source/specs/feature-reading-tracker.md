# 기능 정의서: 독서 기록 앱

## 1. 개요

### 1.1 목적
읽은 책을 기록하고 관리하는 **간단하고 직관적인** 앱을 만듭니다.

### 1.2 대상 사용자
- 독서를 즐기는 일반 사용자
- 읽은 책을 기억하고 싶은 사람
- 독서 습관을 쌓고 싶은 사람

### 1.3 핵심 가치
> "3초 만에 읽은 책을 기록하고, 언제든 돌아볼 수 있다"

## 3. 상세 기능 명세

### 3.1 F-01: 내 책장 보기

**입력**
- 없음 (저장된 전체 목록 표시)

**출력**
- 책 카드 목록 (최신순 정렬)
- 각 카드: 표지, 제목, 저자, 읽은 날짜, 별점

**비즈니스 로직**
- 최신에 읽은 책이 맨 위에 표시
- 빈 목록일 경우: "아직 읽은 책이 없어요" 안내 문구 + 추가 버튼

**예외 처리**
- 데이터 로딩 실패 시: "다시 시도" 버튼 표시

---

### 3.2 F-02: 책 추가하기

**입력 항목**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 제목 | 텍스트 | O | 책 제목 (최대 100자) |
| 저자 | 텍스트 | O | 저자명 (최대 50자) |
| 읽은 날짜 | 날짜 | O | 언제 읽었는지 |
| 별점 | 1~5 | O | 1~5 별점 |
| 한줄 평 | 텍스트 | X | 자유 메모 (최대 200자) |

**유효성 검사**
- 제목: 1자 이상, 100자 이하
- 저자: 1자 이상, 50자 이하
- 읽은 날짜: 오늘 이전 날짜만 (미래 날짜 불가)
- 별점: 1~5 정수

**저장 후**
- 메인 화면(내 책장)으로 이동
- "저장되었습니다" 토스트 메시지

---

### 3.3 F-03: 책 상세 보기

**표시 정보**
- 책 표지 (없으면 기본 이미지)
- 제목, 저자
- 읽은 날짜
- 별점 (1~5)
- 한줄 평 (있을 경우)

**액션 버튼**
- 수정: 수정 화면으로 이동
- 삭제: 삭제 확인 다이얼로그 표시

---

### 3.4 F-04: 책 수정하기

**수정 가능 항목**
- 읽은 날짜
- 별점
- 한줄 평

**비고**
- 제목, 저자는 수정 불가 (잘못 추가 시 삭제 후 재등록)

---

### 3.5 F-05: 책 삭제하기

**플로우**
1. 삭제 버튼 클릭
2. 확인 다이얼로그: "정말 삭제하시겠습니까?"
3. 확인 → 삭제 → 메인 화면으로 이동
4. 취소 → 다이얼로그 닫기

## 4. 데이터 구조 (간단 버전)

### 책 기록 (BookRecord)

```json
{
  "id": "book_001",
  "title": "클린 코드",
  "author": "로버트 C. 마틴",
  "readDate": "2026-02-15",
  "rating": 5,
  "note": "개발자라면 꼭 읽어야 할 책!"
}
```

### 저장 방식 (MVP)
- **로컬 스토리지**: 브라우저 localStorage 사용 (간단한 데모용)
- **추후**: 서버 API 연동 시 사용자별 DB 저장
