# 데이터베이스 스키마

## users 테이블

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | INTEGER | Primary Key |
| email | TEXT | 구글 이메일 (UNIQUE) |
| name | TEXT | 사용자 이름 |
| avatar | TEXT | 프로필 이미지 URL |
| role | TEXT | admin / user |
| status | TEXT | active / pending / blocked |
| created_at | DATETIME | 생성일시 |

## site_settings 테이블

| 컬럼 | 타입 | 설명 |
|------|------|------|
| key | TEXT | 설정 키 (Primary Key) |
| value | TEXT | 설정 값 |

## sessions 테이블

| 컬럼 | 타입 | 설명 |
|------|------|------|
| sid | TEXT | 세션 ID (Primary Key) |
| sess | TEXT | 세션 데이터 (JSON) |
| expired | DATETIME | 만료일시 |
