홈 기획서 가이드 API

마크다운으로 만드는
스마트한 기획 문서

Git 기반 문서 관리로 팀 전체가 동일한 맥락에서 개발할 수 있습니다.

주요 기능

기획서 작성에 필요한 모든 것이 준비되어 있습니다.

📱

화면 미리보기 연동

기획 문서에서 바로 HTML 화면 목업을 모바일/태블릿/데스크톱으로 확인하세요.

🔀

Mermaid 다이어그램

플로우차트, 시퀀스, ERD 등 다양한 다이어그램을 마크다운으로 바로 작성하세요.

📊

프레젠테이션 모드

기획 문서를 그대로 슬라이드로 변환하여 팀 리뷰에 활용하세요.

🔒

접근 권한 관리

Google OAuth로 팀원만 접근할 수 있는 사내 전용 문서 공간을 운영하세요.
