# 시스템 아키텍처

## 전체 구조

```
[사용자] → [Nginx] → [Express Server] → [Static Files (dist/)]
                                       → [SQLite DB]
                                       → [Astro Builder]
```

## 주요 컴포넌트

1. **Express 서버**: 인증 및 정적 파일 서빙
2. **Astro Starlight**: 마크다운 → HTML 변환
3. **SQLite**: 사용자 관리 및 설정 저장
4. **Chokidar**: 파일 변경 감시
